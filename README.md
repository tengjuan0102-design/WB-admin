# 旺宝 AI 后台设计模板

用于共享旺宝 AI 后台产品的视觉规范、导航方案和常用页面模板，帮助产品、设计与研发在同一套可交互页面上快速对齐方案。

本项目主要用于设计评审、原型搭建和页面复用，不是直接接入生产环境的完整业务系统。页面数据与交互默认采用 Mock 内容，使用时按实际需求替换。

## 模板内容

- 设计规范：品牌色、文字、间距、圆角、基础组件和交互状态
- 导航模板：折叠侧栏、并列侧栏、顶部 + 折叠侧栏、顶部 + 并列侧栏
- 列表模板：标准列表、Tab 列表、树形 + 表格
- 表单模板：基础表单、步骤表单、抽屉表单
- 详情模板：基础详情、详情 + 关联列表、抽屉详情
- 通用交互：弹窗、抽屉、操作确认、消息反馈和页面状态
- 登录页：多种布局切换及全局主题色联动

## 使用方式

### 产品和设计评审

运行项目后，通过左侧“交互视觉”目录查看不同导航与页面模板。可在偏好设置中切换导航布局、深色侧栏和主题配置，确认整体框架后再补充业务内容。

### 使用 AI 快速搭建

仓库根目录提供通用的 [AI 后台搭建指令](./AI-ADMIN-BUILDER.md)，支持两种模式：从 0→1 搭建完整后台框架，或在现有后台中增加单个业务模块。它不绑定具体 AI 产品，可提供给具备代码仓库读写能力的工具使用。

Codex 用户还可以直接调用 `$wangbao-admin-scaffold` Skill；两种入口遵循相同的需求访谈、确认单和页面生成规则。

### 研发复用

新增业务页面时，优先选择最接近的列表、表单或详情模板，保留页面结构和设计变量，再替换字段、数据请求及业务逻辑。不要在业务页面中重复写死品牌色和全局间距。

## 设计基准

- UI 框架：Ant Design Vue
- 图标库：Lucide
- 默认品牌主色：`#F04447`
- 内容页面保持浅色，深色方案主要用于导航区域
- 表单统一采用左侧标签、右侧组件的横向结构
- 全局样式通过旺宝主题变量集中控制

## 本地运行

环境要求：Node.js 20.15 及以上版本，pnpm 9 及以上版本。

```bash
pnpm install
pnpm dev:antd
```

默认访问地址：`http://localhost:5666`

## 代码检查

```bash
pnpm -F @vben/web-antd run typecheck
```

提交时还会运行格式、Lint、Stylelint 和完整类型检查。

## 主要目录

- 后台模板应用：`apps/web-antd`
- 页面模板：`apps/web-antd/src/views/style-guide`
- 路由与菜单：`apps/web-antd/src/router/routes/modules`
- 公共页面组件：`apps/web-antd/src/components`
- 旺宝主题配置：`apps/web-antd/src/wb`
- 通用 AI 搭建指令：`AI-ADMIN-BUILDER.md`
- 框架生成 Skill：`.agents/skills/wangbao-admin-scaffold`

## 二次使用说明

复制本项目作为新后台起点时，建议先确定产品范围、导航结构和品牌主色，再选用对应页面模板。示例中的商户、门店、设备、交易等数据仅用于表达布局，不应直接作为真实业务模型或接口定义。

本项目基于 [Vben Admin](https://github.com/vbenjs/vue-vben-admin) 开发，并遵循其开源许可。
