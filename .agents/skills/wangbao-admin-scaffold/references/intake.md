# 产品经理输入模板

填写已知内容即可；未填写项由 Skill 使用默认方案。

## 必填

- 产品名称：
- 需求范围：系统服务谁，主要解决什么问题？
- 核心对象：例如商户、门店、设备、订单、员工。
- 核心操作：例如查询、新增、编辑、审核、导出。
- 导航结构：写出一级、二级菜单；不确定时只写模块名称。
- 导航形式：折叠侧栏 / 并列侧栏 / 顶部加侧栏 / 由 Skill 建议。
- 主色：HEX、RGB 或一张品牌参考图。

## 可选

- Logo 或品牌名称：
- 登录页文案：
- 首页需要展示的指标：
- 需要优先搭建的 3 个页面：
- 页面参考图或竞品链接：
- 必须保留或禁止出现的内容：

## 可直接复制的调用示例

使用 `$wangbao-admin-scaffold` 搭建一个门店设备管理后台。用户是品牌运营和门店管理员；核心对象包括商户、门店、设备和告警。导航使用并列侧栏，包含工作台、商户管理、门店管理、设备管理和系统设置。主色为 `#F04447`。优先完成商户列表、门店详情和设备告警列表，其余页面先提供可导航骨架。
