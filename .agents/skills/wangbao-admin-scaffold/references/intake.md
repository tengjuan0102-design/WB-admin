# 产品经理输入模板

请直接回复下面的问题。可以使用日常产品语言，不需要提供代码、接口或数据库设计；不确定的项目写“请建议”即可。

## 第一轮：搭建框架所需内容

1. **产品名称与用途**：叫什么？主要给谁使用？解决什么问题？
2. **业务范围**：需要管理哪些对象，例如商户、门店、设备、订单或员工？
3. **主要操作**：用户通常要查询、新增、编辑、审核、导出还是查看详情？
4. **导航目录**：期望有哪些一级、二级菜单？只有模块名称也可以。
5. **导航形式**：折叠侧栏、并列侧栏、顶部加侧栏，或由 Skill 根据层级建议。
6. **优先页面**：最先需要搭好的 1–5 个页面，以及每个页面最重要的操作。
7. **品牌主色**：提供 HEX、RGB，或上传一张可以取色的品牌图。

## 第二轮：可选补充

- Logo 或品牌名称：
- 登录页文案：
- 首页需要展示的指标：
- 页面参考图或竞品链接：
- 必须保留或禁止出现的内容：

收到回复后，先输出一份“搭建确认单”，列出导航结构、页面清单、主色和必要假设。用户确认后再生成页面。

## 可直接复制的调用示例

使用 `$wangbao-admin-scaffold`。请先通过对话引导我提交搭建后台框架所需的信息，整理确认单后再生成页面。
