# 模式选择

使用 Skill 后，先选择一种模式：

- **0→1 整体搭建**：适合新产品，需要规划完整后台框架、导航、主题和首批页面。
- **单模块增量**：适合已有后台，只增加一个具体模块或功能，不改动无关页面。

如果用户已经描述清楚，自动选择对应模式，无需重复提问。选择后仅读取对应清单：

- [0→1 整体搭建输入清单](intake-zero-to-one.md)
- [单模块增量输入清单](intake-module.md)

## 启动示例

使用 `$wangbao-admin-scaffold`。我需要从 0→1 搭建一个新后台，请进入对话模式收集需求。

使用 `$wangbao-admin-scaffold`。我需要在现有后台增加一个设备告警模块，请进入单模块增量模式收集需求。
