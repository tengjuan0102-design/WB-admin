# 旺宝后台 UI 约定

## 全局视觉

- 内容页面保持浅色；深色方案只作用于导航区域。
- 品牌色由主题变量统一驱动。正文、边框、禁用态使用中性色，不滥用品牌色。
- 页面使用统一浅灰底和白色内容卡片；优先复用现有 `wb-page-shell` 与主题 token。
- 面包屑不显示底部分割线，层级分隔符使用 `/`。

## 导航

- 深色主导航的选中项使用品牌色背景和白色文字。
- 并列导航的浅色右栏：选中项只将文字标为品牌色，不加背景；hover 同样不加背景。
- 浅色导航的左侧当前层级可以使用浅品牌色背景和品牌色文字。
- 菜单文案采用业务对象或任务名称，避免“示例一”“页面二”等占位命名。

## 页面结构

- Tab 可以承担页面标题；此时不要再重复显示同名标题。
- 列表页包含标题/Tab、筛选区、操作区、数据区和分页。Mock 数据应足以看出筛选、分页或 Tab 切换效果。
- 详情页使用字段标签与字段值展示，不要退化成无结构的普通文本。
- 详情加关联列表应同时呈现概要指标、字段详情、筛选区、表格标题、导出操作和分页。

## 表单与弹窗

- 表单统一采用左侧标签、右侧组件的横向结构；标签固定宽度并右对齐。
- 查询按钮通常靠右，操作顺序按“次要操作 → 主要操作”排列。
- 常规小型表单弹窗默认宽度约 `520px`，内容四周 `24px`；内容区与标题、底部操作区保持清晰间距。
- 文字按钮 hover 只高亮文字，不增加背景。
- 弹窗字段较多时才扩大宽度或启用内容区滚动，避免为了展示规范制造不真实的大弹窗。

## 验收

- 导航选中态、hover、展开层级正确。
- 页面无重复标题、无多余分割线、无明显空白或拥挤。
- 标签、输入框、按钮和表格列对齐。
- 主题色变化后，导航、按钮、链接、选中态与登录页同步更新。
- 主要页面在常用桌面宽度下无横向溢出。
